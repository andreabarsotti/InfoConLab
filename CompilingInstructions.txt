In order to execute a cpp file from the terminal, do these steps:

- Save the file as a .cpp
- Open the cmd (Wind+R -> cmd)
- Go to the right folder (cd "path-to-folder")
- write in cmd g++ sourcefile_name.c -o outputfile.exe (this compiles the cpp file creating an exe version)
- write outputfile.exe 
(this opens the outputfile.exe, thus executing the code: if it doesn't work, write .\outputfile.exe)
